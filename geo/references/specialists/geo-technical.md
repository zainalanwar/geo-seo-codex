# Technical access

For each sampled URL, record redirects, final status, content type, canonical, robots meta and X-Robots-Tag. Check the relevant robots.txt group, sitemap discovery and internal link path. Read the initial HTML for substantive content and links. If it differs from a rendered view, document the exact missing text or link and whether a render was available. Compare directives with the publisher's intended indexing policy.

Inspect mobile viewport, layout and performance only with the relevant measurement. Record device, date and data source for Core Web Vitals. Distinguish field measurements from lab diagnostics. Document CDN challenges or rate limits and the client identity used. Treat verified crawler logs as independent evidence when available.

Return affected URLs, evidence, expected behavior, user or discovery impact and a verification step for each proposed fix. Apply [the shared rubric](../scoring.md).
