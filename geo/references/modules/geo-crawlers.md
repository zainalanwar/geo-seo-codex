# GEO crawlers

Fetch the effective robots.txt, response status, redirects and headers for each relevant origin. Read applicable crawler groups, wildcard fallback and path matching, including longest matches and allow/disallow ties. Check sample page HTTP status, robots metadata, X-Robots-Tag and canonical. Keep crawl permission and indexing directives distinct.

Classify agents by current provider documentation (search, training, user-initiated or other). Record agent, purpose, URL, rule, observed HTTP response and uncertainty. A simulated user agent does not establish access by a verified provider crawler. Note CDN challenges and use verified logs when available. Respect the owner's training preferences. Missing llms.txt carries no penalty. Provide targeted fixes for unintended search restrictions.
