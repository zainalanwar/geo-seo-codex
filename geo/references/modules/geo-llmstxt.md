# GEO llmstxt

For analysis, retrieve /llms.txt and inspect HTTP status, MIME type, redirect and body (a branded HTML fallback is not a Markdown file). Validate the title, summary, grouped links, optional section and referenced URLs against current first-party pages. Treat this file as optional publisher guidance.

For generation, inventory canonical public pages and draft Markdown containing one H1, a concise blockquoted description and grouped links with accurate descriptions. Keep private, duplicate and staging URLs out. Preview the content and validate each included link. Write a local draft or the requested source file. Report checks and any unavailable URLs.
